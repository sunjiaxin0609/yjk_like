# yjk_like

对标盈建科（YJK）的结构计算设计软件。

**技术路线**：C++17 内核 + Qt6 桌面端，零外部数值库依赖（仅标准库）。

**当前规模**：约 26200 行（内核头 6833 / 内核实现 5896 / 测试 8698 / Qt 界面 4786 / 命令行）。

## 快速上手

### 命令行：静态分析

```bash
yjk run examples/frame3x4.yjk -o out/frame3x4
```

写出三个文件：

| 文件 | 用途 |
| --- | --- |
| `out/frame3x4.html` | 浏览器直接打开：三维变形动画、应力云图、内力图、楼层表（离线单文件，零依赖） |
| `out/frame3x4.json` | 结果数据，自带 `_schema` 字段说明定长数组含义 |
| `out/frame3x4.txt` | 文本报告：位移包络、楼层指标、构件应力 TOP10、平衡校核 |

### 命令行：动态分析（模态 + 反应谱 + 荷载组合）

```bash
yjk run examples/frame3x4_dynamic.yjk -o out/frame3x4_dynamic
```

在静态三件套之外多出 `*.dynamic.json` 与 `*.dynamic.txt`（模态频率/周期/参与质量、
谱工况 Ex/Ey/Ez 层剪力、各组合内力与包络）。脚本要点：

```
case D                          # 工况分组：后续荷载归入 D
selfweight on
slabload   4
case L
slabload   2
case W
nodeload top 12 0 0             # 顶层 X 向水平力

gmass D L 0.5                   # 恒 + 0.5 活自动转质量（GB 50011 5.1.3，ψ 默认 0.5）
modal auto                      # 振型数自动：max(9, 层数×3)（GB 50011 每方向 ≥ 9）
spectrum 0.16 0.40 cqc          # αmax=0.16（8 度小震）, Tg=0.40s, CQC 组合（第三参）
                                #   第 4 参可写竖向系数 k（默认 0.65，GB 50011 5.3.1）

combo standard  S1  D L         # 标准组合 G+Q
combo basicvar  B1  D L W       # 基本组合·可变控制 1.2G+1.4Q+1.4·0.7W
combo basicperm B2  D L W       # 基本组合·永久控制
combo seismic   SE  D L Ex      # 地震组合 1.2(G+0.5Q)+1.3Ex
```

框架示例（`examples/frame3x4_dynamic.yjk`）验证结果：前 6 阶频率
`[3.064, 3.064, 3.70, 9.617, 9.617, 11.48] Hz`（X/Y 对称平动 + 扭转），
X 向质量参与系数 **91.8%**（≥90% 达标），地震组合 SE 层剪力 536/424/231 kN。

输出多出逐层 **剪重比**（V/W，W 为该层及以上合计重力代表值）与
`[重力代表值]` 段（恒 + ψ·活，GB 50011 5.1.3 口径）。

### 不建板方案（真实工程常规做法）

```
grid.slab    off                 # 不生成楼板壳单元
slabload.to  beam                # 楼面荷载按 45° 线导到梁上
slabload     4
diaphragm    on                  # 刚性楼板假定（平面内刚度）
```

三件事**缺一不可**：只关掉板而不导荷，楼面荷载会凭空消失——而模型照样可解、
残差正常，只有"施加荷载与竖向反力对不上"这一条能暴露它。
`slabload` 会打印总荷载，请与报告里的反力合计对账。

### 桌面端

```bash
scripts/build-gui.sh --run
```

界面里打开一个 `.yjk` 脚本，按 `F5` 就算。

## 构建与测试

### 内核（无外部依赖，可在 CI / 服务器上跑）

```bash
cmake -B build -G Ninja -DCMAKE_MAKE_PROGRAM=<ninja路径> \
      -DCMAKE_CXX_COMPILER=<g++路径> -DYJK_BUILD_TESTS=ON
cmake --build build
ctest --test-dir build --output-on-failure
```

需要 CMake ≥ 3.16 与任一 C++17 编译器（GCC / MSVC / Clang）。
本机验证过的两套编译器：GCC 16.2（w64devkit）与 GCC 13.1（Qt 自带 MinGW），
分别建独立构建目录（如 `build-p1` / `build-g131-p1`）各跑一遍全绿。

### Qt6 桌面端

```bash
scripts/build-gui.sh            # 配置 + 编译 + 跑全部测试
scripts/build-gui.sh --deploy   # 再打一个可独立拷贝的 dist/
scripts/build-gui.sh --run      # 编译后直接启动
```

脚本会自动用 **Qt 自带的 MinGW** 编译。Qt 与 MinGW 版本必须配套
（6.8.3 对应 GCC 13.1.0）；用系统里别的 GCC 编会得到
"能编过、一运行就崩"——因为链接期会和 Qt 的 DLL 抢 `libstdc++-6.dll`。

首次需要装 Qt（一次性，约 300 MB）：

```bash
pip install aqtinstall
python -m aqt install-qt   windows desktop 6.8.3 win64_mingw \
       -O C:/toolchain/Qt --archives qtbase
python -m aqt install-tool windows desktop tools_mingw1310 \
       qt.tools.win64_mingw1310 -O C:/toolchain/Qt
```

`--deploy` 产出的 `dist/`（约 32 MB）已用 `windeployqt` 收齐运行库，
**拷到没有装 Qt 的机器上双击即可运行**。

## 核心设计约定

- **单位**：内部统一 `kN-m-N`（长度 m，力 kN，应力 kPa）
- **内核不依赖 Qt**：界面只读内核数据，便于独立测试与将来做服务端
- **绝不静默出错**：奇异、不收敛、精度不足必须给出可读诊断
- **未验证的代码等于零**：每个单元/算法都必须对标解析解或独立实现
- **每个单元必修课**：刚体模式 + 倾斜/旋转用例从单元刚写完时就加，
  不能等后面某个功能"照出来"（MITC4 与导荷两轮各抓到一个位移正常、
  只有刚体判据能抓的 bug，详见 NOTES 5.14~5.19）

详细的架构说明、技术难点与踩坑记录，见 [`NOTES.md`](NOTES.md)。

## ✅ P1（已完成）：端部释放（铰）+ 弹簧单元

**端部释放（铰）** —— 2026-10-09 完成

- 实现：`BeamElement3D` 支持 i/j 端各 6 自由度**选择性释放**，局部刚度静力凝聚
  （Guyan condensation），释放自由度处内力恒为 0；贯通 Model API
  （`releaseAt`/`setReleases`）与 `.yjk` 脚本命令
- 判据：两端铰接杆横向荷载下铰端弯矩恒 0；简支铰接梁跨中挠度对标
  **含剪切修正**解析解 `PL³/48EI·(1+Φ)`（`Φ = 12EI/(G·As·L²)`，
  rel 误差 1.9e-16）；悬臂释放对标 `PL³/3EI·(1+Φ/4)`
- 配套修复：零刚度自由度的自动锁定判据从"节点整体有无荷载"
  细化为**按该分量方向有无荷载** —— 悬臂释放 + 同节点其它方向有荷载时
  不再误报"无刚度"；而"零刚度 + 该方向带荷载"仍由 `check()` 拦截
  （防止荷载被悄悄吞掉）
- 自带**刚体模式 + 45° 倾斜 + 绕轴旋转**用例：弯曲平面随 up 旋转，
  `up=-Y` 时荷载沿局部 z' → **弱轴弯曲**（实测挠度与 `Iy` 解析解吻合）

**弹簧单元** —— 2026-10-09 完成

- 6 个自由度方向各自独立刚度（`SpringElement3D` + `init` API），
  局部→全局变换；k = 0 表示释放，大 k 近似刚接
- 解析解验证：轴向 `u = P/k`、串联 `k₁k₂/(k₁+k₂)`、并联分配、
  45° 倾斜投影刚度 `k·cos²θ`
- k=0 释放语义：无荷载方向自动锁定（dof=-1，可求解）；该方向带荷载时
  `check()` 拦截（零刚度不能吞荷载）
- 平动刚体零内力（rel 1e-15）、局部刚度对角结构、不同方向无耦合

## ✅ P2：剪力墙 + 墙面网格（已完成，2026-10-09）

## 🔵 P5：工程化

逐节点比对位移；建一套经典算例集：门式刚架、框架-剪力墙、错层结构、大底盘。

- 目前无自动重编号（RCM 不适用于 Cholesky，见 NOTES 3.3），
  靠"建模时按楼层自上而下编号"的人工约束

  的排序（数学层已踩过的坑）

平面简图、轴网标注、构件编号、配筋示意。

**导入导出** —— 与既有工程数据互通：YJK/PKPM 模型、DXF 底图、IFC。

**其他** —— 温度荷载、施工模拟（单元生死，高层竖向变形差必用）、
P-Δ 二阶效应（几何刚度）、结果动画导出（GIF/MP4）。
